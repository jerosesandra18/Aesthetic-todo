# Aesthetic To-Do List

A beautifully designed and minimal To-Do List web application focused on clean UI, smooth user experience, and productivity.

---

## Features

-  Elegant aesthetic design  
-  Dark Mode with consistent color theme  
-  Add and manage daily tasks  
-  Delete completed tasks  
-  Data stored using Local Storage (no data loss on refresh)  
-  Fast and responsive performance  

---

## Tech Stack

- HTML5 – Structure  
- CSS3 – Styling & Aesthetic UI  
- JavaScript (Vanilla) – Functionality & Logic  

---

## Project Structure

- index.html – Main structure  
- style.css – Styling & themes  
- script.js – App logic  

---

## How to Run Locally

1. Download or clone this repository  
2. Open index.html in your browser  
3. Start managing your tasks
